Control audio test

This short musical tone is bundled inside the APK and loops. It tests whether Android WebView itself can keep audio playing when this application goes into the background.

How to test

1. Tap the Play button above.
2. Tap Send to background in the app footer.
3. Listen while using another app.
4. Return and tap Log result.
5. Repeat with the phone's screen locked.

If this sample continues but YouTube Music stops, the issue is probably specific to YouTube Music, sign-in, or its playback behavior rather than a universal WebView limitation.
